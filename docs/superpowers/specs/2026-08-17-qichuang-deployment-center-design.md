# 启创动力部署中心 HTML 原型设计

## 目标

构建一个可直接在现代浏览器中运行的单页部署安装原型，帮助实施工程师选择部署目标、检查运行环境、配置云效与 Harbor 凭据、模拟部署，并生成部署交付清单。原型不执行真实 SSH、Docker 或安装命令，也不连接真实数据库。

## 使用对象与成功标准

- 使用对象：实施工程师、运维工程师、项目交付人员。
- 主要场景：远程 Linux 部署、本机 Docker Desktop 部署、部署前预检、部署材料配置和交付信息整理。
- 成功标准：用户可以在一个页面内完成三步流程，并在完成页查看部署清单和进入后台系统。

## 信息架构

页面采用横向三步工作台：

1. 顶部品牌栏展示 Logo、产品名称“启创动力 · 部署中心”和部署器状态。
2. 品牌栏下方展示“部署目标”“安装方式与部署”“部署完成”三个步骤。
3. 主工作区在桌面端分为当前任务区和右侧部署摘要区。
4. 当前步骤底部提供与任务匹配的主要操作。
5. 平板和手机端切换为单栏，右侧摘要移动到当前任务下方。

## 三步流程

### Step 1：部署目标

用户先在“远程 SSH”和“本机部署”之间选择一种部署目标，两种方式使用分段控制器切换。

#### 远程 SSH

用于通过 SSH 部署到 Linux 服务器，字段包括：

- 目标名称
- 服务器地址
- SSH 端口，默认 `22`
- 登录用户
- 连接认证：密码或私钥文件
- 选择密码时显示 SSH 密码
- 选择私钥文件时显示私钥路径和可选的私钥口令

#### 本机部署

用于本机 Docker 部署。Windows 和 macOS 会在 Docker Desktop 本机启动服务与中间件，并连接独享的远程 openGauss。字段包括：

- 数据库 Owner
- 远程 openGauss 地址
- openGauss 端口，默认 `5432`
- 运维用户名
- 运维密码

#### 环境预检

点击“检查环境”后模拟连接并依次展示以下结果：

- Docker：版本与运行状态
- 架构：目标架构及兼容状态
- 磁盘：可用空间与最低要求
- 权限：Docker 或目标目录操作权限

每一项显示等待、检查中、通过或失败状态。默认演示路径全部通过。未完成预检或存在失败项时禁用“下一步”。底部操作为“检查环境”和“下一步”。

### Step 2：安装方式与部署

页面说明运行材料和依赖镜像从云效 Runtime Bundle 获取，并提示用户确保网络连接正常。

#### Runtime Bundle

- Runtime Bundle 版本：默认“最新版本”，也允许输入指定版本
- 云效 Generic 用户名
- 云效 Generic 密码或令牌

#### Harbor 镜像仓认证

- Harbor 用户名
- Harbor 密码或机器人令牌

页面明确说明：在线部署会在拉取私有镜像前登录 Harbor；密码不写入部署器、运行根或日志；Docker 会依照本机或目标机自身的凭据存储策略管理登录态。

对于本机部署，页面额外说明：本机部署使用部署器管理的运行根；Windows 和 macOS 的远程 openGauss 凭据由 qcdl 写入此运行根，不保存到部署器历史。

底部操作为“上一步”和“开始部署”。所有凭据字段均为必填，密码默认遮罩。开始部署后锁定可能造成状态冲突的字段，展示总体进度、当前任务、已用时间和等宽终端日志。模拟任务包含获取 Runtime Bundle、登录 Harbor、拉取镜像、准备运行根、启动中间件、启动应用和健康检查。全部完成后自动进入 Step 3。

原型提供“故障演示”开关。启用后，部署在“拉取镜像”阶段模拟 Harbor 身份认证失败；未启用时保持原有成功流程。失败后进度停止，当前任务显示“部署失败”，终端日志追加不含敏感凭据的红色错误行，并在日志上方展开内联错误面板。

错误面板显示失败阶段、错误代码 `DEPLOY-IMG-401`、脱敏原因“Harbor 身份认证未通过”以及检查用户名、密码或机器人令牌的处理建议。面板提供“修改认证信息”和“重新部署”：前者解锁表单并将焦点移动到 Harbor 用户名，后者重新校验当前字段并从第一项任务重新执行。故障演示开关保持用户当前选择，避免恢复行为隐式改变演示条件。

### Step 3：部署完成与交付清单

完成页首先显示部署成功状态、部署目标、Runtime Bundle 版本和完成时间，然后集中展示部署交付清单：

- 关系数据库：类型、地址、端口、数据库名、Owner 或用户名、密码
- 时序数据库：类型、访问地址、组织、存储桶、令牌或密码
- 文件存储：类型、服务地址、控制台地址、Access Key、Secret Key
- 后台系统：访问地址、管理员账号、管理员密码
- 部署信息：目标名称或本机环境、运行根、版本、部署时间

密码、令牌和密钥默认遮罩，支持逐项显示或隐藏。每个字段支持复制，页面也支持复制完整交付清单。

完成页提供两个明确操作：

- “下载交付清单”：生成并下载 UTF-8 编码的 TXT 文件，内容包括部署摘要、关系数据库、时序数据库、文件存储和后台系统的完整地址与凭据。文件名采用 `启创动力-部署交付清单-YYYYMMDD-HHmm.txt`。下载前显示敏感信息保管提示，用户确认后执行下载。
- “登录系统”：使用后台系统访问地址打开新标签页。若地址无效则阻止打开并显示明确提示。

## 表单校验

- 当前部署方式对应的可见字段必须填写，隐藏方式的字段不参与校验。
- SSH 端口和 openGauss 端口必须为 1 至 65535 的整数。
- 服务器地址和 openGauss 地址接受主机名、IPv4 或 IPv6，不在纯前端原型中探测其真实性。
- 私钥认证必须提供私钥路径，私钥口令允许为空。
- 所有错误信息显示在对应字段附近，并将焦点移到第一个错误字段。

## 数据与安全边界

- 所有表单状态仅保存在当前页面内存中，刷新页面即清除。
- 演示生成的数据库、时序库、文件存储和后台凭据使用浏览器随机数能力生成，不在源代码中保存固定凭据。
- 用户输入的 SSH、openGauss、云效和 Harbor 凭据不写入本地存储、部署器历史或日志。
- 日志只显示脱敏后的用户名、地址和操作结果，不显示密码、令牌、私钥路径或私钥口令。
- 页面不包含后端服务、持久化、远程请求或真实环境检测能力。
- 导出的清单属于演示数据，但界面仍按敏感信息处理并提示保存在受控位置。

## 视觉设计

采用已确认的深色运维终端风格。背景使用近黑和深炭灰，表单与清单使用层级更高的深灰。品牌橙用于当前步骤、主按钮、进度和焦点状态。绿色表示通过，黄色表示警告，红色表示失败。

顶部品牌栏提供暗色和亮色两种主题模式，默认使用暗色。暗色保持运维终端的近黑背景；亮色使用浅灰工作区、白色面板和深色文字，同时保留品牌橙主按钮与状态色。主题切换即时生效，主题偏好可单独写入浏览器本地存储，但不得写入任何部署表单、密码、令牌或私钥信息。旧的无效主题偏好统一回退为暗色。

Logo 使用用户提供的 `logo11@4x.png`，复制为项目本地资产并保持原始比例。表单标签使用清晰的中文无衬线字体栈，地址、版本、端口、检查值和部署日志使用等宽字体。动效仅用于步骤切换、预检结果、部署进度和短暂反馈。

## 交互与错误处理

- 步骤导航只能进入当前步骤或已完成步骤，不能跳过未完成步骤；部署成功进入 Step 3 后，Step 1 和 Step 2 导航锁定，当前会话不可返回修改。
- 切换部署目标或 SSH 认证方式时保留已输入字段，但只校验当前可见字段。
- 检查与部署运行期间禁用会造成状态冲突的操作。
- 预检失败时显示对应修复建议，并允许重新检查。
- 部署失败时停止进度与计时，在日志上方显示内联错误面板，并解锁可恢复操作。
- “修改认证信息”定位 Harbor 凭据；“重新部署”重新校验并从第一项任务开始，不复用上一次进度或日志。
- 错误面板、日志和提示不得包含密码、令牌、私钥路径或私钥口令。
- 复制 API 不可用时显示失败提示，不虚报成功。
- 下载交付清单由浏览器本地生成 Blob，不上传数据；用户取消敏感信息提示时不创建文件。
- “登录系统”始终使用 `noopener,noreferrer` 打开新标签页。

## 技术方案

交付物采用原生 HTML、CSS 和 JavaScript，避免安装依赖，双击 `index.html` 即可运行：

- `index.html`：语义化页面结构和三步内容
- `styles.css`：设计令牌、布局、组件状态、动效和响应式规则
- `app.js`：页面状态、校验、模拟预检、模拟部署、凭据生成、复制、下载和登录跳转
- `assets/logo.png`：部署中心使用的品牌 Logo

页面使用单一内存状态对象驱动步骤、部署方式、认证方式、表单、预检结果、部署进度和交付凭据。DOM 更新函数按功能边界拆分，避免状态散落在事件处理器中。

## 验收与测试

1. 页面通过本地文件方式加载时，Logo、样式和脚本均正常。
2. 远程 SSH 的密码认证和私钥认证都能完成校验与预检。
3. 本机 Docker 方式能填写远程 openGauss 信息并完成预检。
4. 未预检、预检失败、字段无效或凭据缺失时无法继续。
5. Runtime Bundle、云效和 Harbor 字段完整，安全说明随部署方式正确显示。
6. 模拟部署的百分比、当前任务、已用时间和日志保持一致，日志不包含敏感值。
7. 启用故障演示时，流程在“拉取镜像”阶段停止并显示 `DEPLOY-IMG-401` 内联错误面板；未启用时仍可正常完成。
8. “修改认证信息”能够解锁表单并聚焦 Harbor 用户名；“重新部署”会清空上次进度和日志并重新执行。
9. 错误面板在桌面和移动端均无文字遮挡或按钮溢出，且不显示任何敏感凭据。
10. 完成页包含关系数据库、时序数据库、文件存储、后台系统和部署信息。
11. 密码显隐不改变原始值，单项复制和复制完整清单内容正确。
12. “下载交付清单”在确认后生成符合命名规则的 UTF-8 TXT 文件，文件包含全部部署摘要和交付凭据；取消确认时不下载。
13. “登录系统”使用完成页中的后台地址打开新标签页。
14. 刷新页面不保留 SSH、openGauss、云效或 Harbor 凭据。
15. 桌面、平板和手机宽度下无文字遮挡、横向溢出或按钮错位。
16. 键盘可以访问步骤、表单、分段控制器、按钮和密码控制，焦点清晰可见。

## 不在本期范围

- 真实 SSH 连接、Docker 检测和服务器环境检测
- 真实下载 Runtime Bundle、Harbor 登录、镜像拉取或部署执行
- 后端 API、用户认证、权限控制和部署历史
- 保存、同步或恢复部署任务
- PDF、Excel 或 Word 格式的交付报告
